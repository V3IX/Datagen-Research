# Datagen — Research

Research repository for a paper on **measuring how overfitted trading strategies are**, and how well current validation methods detect it, using synthetic market data where the true answer is known. Paper will also check if synthetic data improves strategy more than other methods.

## Why this paper

Most trading today is done by automated strategies fitted on historical data. That data is:

- **limited** — a few decades, with only a handful of crashes and regime changes;
- **biased** — one realised path, dominated by a single market environment (e.g. the US over the last 50 years).

Strategies fitted on it tend to be overfitted: their backtested performance overstates what they will do on unseen data. Practitioners try to correct for this with validation methods — hold-out splits, walk-forward, CPCV, bootstrap, the Deflated Sharpe Ratio.

**The gap:** on real data, nobody can check how well these methods work. There is only one history, the strategy's true performance is unknown, and there is no fresh unseen data to compare against. A validation method produces an estimate, but there is nothing to measure that estimate against.

**Synthetic data closes that gap.** If prices are generated by a known model (GARCH, regime switching, jump diffusion), the true properties of the market are known, and unlimited fresh out-of-sample data can be generated. That makes it possible to:

1. measure the overfitting gap $\Delta$ of a strategy directly, instead of estimating it;
2. compare each validation method's estimate with that true value;
3. see how the results change with data length, number of strategies tried, model flexibility, and market dynamics (calm, regimes, jumps).

## Research questions (draft)

1. How large is the overfitting gap for typical strategy development, under different market dynamics?
2. How accurately do existing validation methods estimate it? Which under- or overestimate, and when?
3. Do conclusions drawn on simple data (Gaussian random walk) still hold when the data has volatility clustering, regimes and jumps?

## Approach (draft)

1. Generate synthetic market histories with known parameters.
2. Develop strategies on one generated history, as a practitioner would on real data.
3. Validate them with each method on that same history.
4. Measure their true performance on fresh generated histories and compare.

## Main limitation

All ground truth is true **inside the generator**. Results carry over to real markets only as far as the generators reproduce real market behaviour — which is why a large part of these notes is about the generators themselves.
